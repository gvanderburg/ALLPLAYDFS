ALLPLAY's custom-domain website is intended to be hosted on Netlify.

**Why:** The user explicitly selected Netlify when asked where allplaydfs.com should be hosted.

**How to apply:** Do not repoint the custom domain to Replit without asking. Distinguish frontend hosting from backend hosting: moving static assets alone must not be described as a complete migration of memberships, authentication, projections, uploads, or notifications.
