ALLPLAY's custom-domain website is intended to be hosted on Vercel.

**Why:** The user changed the requested hosting destination from Netlify to Vercel.

The user reports that allplaydfs.com was purchased through Replit.

**How to apply:** Do not repoint the custom domain to Replit or Netlify without asking. Distinguish frontend hosting from domain registration and backend hosting: moving static assets alone must not be described as a complete migration of memberships, authentication, projections, uploads, or notifications. A domain authorization code comes from the current registrar, not the website's source code.
